# Code accompanying

## *Well-posedness, Stability, and Bifurcation in an Acid-Mediated Tumour Invasion Model with Interspecific Competition*

Yaya Youssouf Yaya & Barka Ibrahim Mahamat — revised submission to *Bulletin of Mathematical Biology*, manuscript BMAB-D-26-00386.

---

Every figure and every numerical claim in the paper is regenerated by the scripts below. No figure hard-codes a parameter value: `params.py` is the single source of truth, and the random seed is fixed to 42.

## Files

| File | Role |
|---|---|
| **`params.py`** | Single source of truth for the three phenotypes of Table 1 (indolent, moderate, aggressive), as a frozen dataclass, plus the critical threshold `delta_c`, the shared grid / time-step constants, and a checker for Hypothesis (HL). Imported by everything else. |
| **`main.py`** | The solver (`Parameters`, `Grid2D`, `Solver`) and most figure generators. The scheme is IMEX: five-point Laplacian with homogeneous Neumann conditions imposed by reflection, assembled as a Kronecker sum; backward-Euler diffusion with sparse LU factorisations computed once and reused; explicit reaction. |
| **`bifurcation_plane.py`** | The $(\alpha, \delta/\delta_c)$ phase portrait and the two transcritical bifurcation diagrams (Fig. 1). Purely analytic — it plots the closed-form equilibrium expressions, with no simulation involved. |
| **`bistability.py`** | The bistable regime (Fig. 6): two runs with *identical* parameters, differing only in the radius of the initial tumour seed, converging to opposite equilibria. |
| **`fisher_kpp.py`** | The travelling-front speed (Fig. 7), measured on a fine mesh over successive late time windows. See the note below. |
| **`sympy_verification.py`** | Symbolic verification of every algebraic claim in the paper: the Routh–Hurwitz coefficients at the coexistence equilibrium; the Sylvester minors that yield Hypothesis (HL); the Sotomayor transversality coefficients on both transcritical curves; the closed-form Routh–Hurwitz identity valid for *every* spatial mode, together with the vanishing of all three two-cycle products of the Jacobian; and the two-branch admissibility of the coexistence equilibrium with its saddle classification. All residuals are exactly zero. |

## Dependencies

- Python ≥ 3.10, `numpy` ≥ 1.20, `scipy` ≥ 1.8, `matplotlib` ≥ 3.5, `sympy` ≥ 1.10

## How to run

```bash
python3 params.py               # prints the three phenotypes and checks (HL)
python3 sympy_verification.py   # symbolic proof of every algebraic claim (~5 s)
python3 bifurcation_plane.py    # -> bifurcation_plane.pdf   (Fig. 1)   (~2 s)
python3 main.py                 # -> Figs. 2, 3, 4, 5, 8                (~10 min)
python3 bistability.py          # -> bistability.pdf         (Fig. 6)   (~3 min)
python3 fisher_kpp.py           # -> fisher_kpp_speed.pdf    (Fig. 7)   (~10 min)
```

Each run prints a short report — parameter values, observed convergence orders, the front-speed ratios, the violation report — so that the printed numbers can be matched against those quoted in the manuscript.

## Two notes on correctness

**The invariant region is not enforced.** The solver runs with `enforce_clip=False` by default. Clipping the iterates into the admissible box would conceal whether the scheme actually preserves it, so instead every step records the worst pointwise violation of each of the six bounds, and `violation_report()` returns the maximum over the run. Across every simulation in the paper the worst excess stays below `1e-14`, which is floating-point round-off. This is the discrete counterpart of Theorem 3.1, and it is a prediction being tested, not a constraint being imposed.

**The convergence study uses nested grids.** Grids are of the form `2^k + 1` (51, 101, 201, 401, 801) so that the coarse nodes are *exactly* a subset of the fine ones. This matters. The more natural-looking sequence 50, 100, 200 has 49, 99, 199 intervals, which do **not** nest, so sub-sampling the fine grid every other node compares the two fields at physically different locations — a silent error that contaminated an earlier version of this study. An assertion in `fig_convergence` now prevents it from recurring.

## On the Fisher–KPP front speed

An earlier version of this code reported a front speed *below* the KPP minimal speed, which is impossible for a front issued from compactly supported data. The cause was not, as we first believed, under-resolution of the exponential wing: refining the mesh from `Nx = 200` to `1600` makes the measured speed *converge*, to `0.983 c*`, and the deficit does not go away.

It was the fitting window. A pulled KPP front approaches its asymptotic speed only algebraically slowly — the Bramson logarithmic delay, `x_f(t) = c* t - (3 / 2 lambda*) ln t + O(1)` — so *any* early-time fit necessarily under-estimates `c*`, by an amount decaying only like `1/t`. Measured on successive late windows with an adequately resolved mesh, the ratio rises monotonically,

| window | [10,20] | [20,30] | [30,40] | [40,55] | [55,75] |
|---|---|---|---|---|---|
| `c_num / c*` | 0.978 | 0.994 | 1.000 | 1.002 | 1.004 |

and crosses 1 from below, as it must. `python3 fisher_kpp.py` reproduces this table.

The small final excess above `c*` is physical, not numerical, and we checked this rather than asserting it. Two further entry points are provided:

```bash
python3 fisher_kpp.py --longtime   # t = 250 on [0,42]      (~80 min)
python3 fisher_kpp.py --edge       # leading-edge structure  (~6 min)
```

`--longtime` settles whether the excess is a slowly decaying transient. It is not: carried to `t = 250` on a domain lengthened to `[0,42]`, with `h` and `dt` unchanged, the ratio *rises and saturates* at `1.0053` (`1.0037, 1.0046, 1.0050, 1.0052, 1.0053, 1.0053` on the six windows from `[55,75]` to `[210,250]`). The first of these reproduces the value obtained on the shorter domain, so the excess is insensitive to the domain length as well as to the mesh. The front is therefore weakly **pushed**.

`--edge` measures why. The acid diffuses two hundred times faster than the cells here (diffusion coefficient `1` against `delta1 = delta2 = 5e-3` in nondimensional units), reaches ahead of the front and depresses the healthy tissue, so the growth rate `beta(1 - alpha N)` felt inside the front exceeds its nominal value `beta(1 - alpha)` — by `11.7%` at the level `T = 1e-1`, `4.1%` at `1e-3` and `1.1%` at `1e-6`, decaying to zero as `T -> 0` and `N -> 1`. Because the enhancement vanishes at the leading edge it leaves the linear spreading speed untouched; because it is substantial in the interior it makes the nonlinear front outrun its own linearisation. Both runs save their data (`fisher_kpp_longtime.npz`, `fisher_kpp_edge.npz`) so the window analysis can be redone without repeating the integration.
